# Amazon-Clone
html , css based amazon clone 

A front-end clone of the Amazon e-commerce website built using HTML and CSS. This project is a static replica of the Amazon homepage, created for learning and practicing web development fundamentals.

 <h1>🚀Features </h1>

-Amazon-like header with logo, search bar, and navigation links      <br>
-Product grid layout  <br>
-Basic footer section  <br>
-Hover effects and UI styling
